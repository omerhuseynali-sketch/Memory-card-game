# 🧠 React Memory Card Game

A fun, interactive, and fully responsive **Memory Card Game** built using **React**. Test and improve your memory by finding all matching pairs of cards in the shortest time or fewest moves possible!

## ✨ Features

*   🎯 **Interactive Gameplay:** Smooth card flipping animations and automatic match checking.
*   📊 **Score Tracking:** Keeps track of your current **move count** and **score/matches found**.
*   🔄 **Instant Restart:** A "New Game" button to shuffle cards and reset the timer/score instantly.
*   📱 **Fully Responsive:** Optimised for desktop, tablets, and mobile screens.
*   ⚡ **React State Management:** Built using modern React hooks (`useState`, `useEffect`).

## 📦 Installation & Setup

Follow these steps to run the project locally on your machine:

### 1. Clone the Repository
```bash
git clone https://github.com
```

### 2. Navigate to the Project Directory
```bash
cd YOUR_REPOSITORY_NAME
```

### 3. Install Dependencies
```bash
npm install
```

### 4. Start the Development Server
```bash
npm run dev
# or 'npm start' if using Create React App
```
Open `http://localhost:5173` (or the port specified in your terminal) to view it in your browser.

## 💡 How the Game Works

1.  The game starts with a grid of shuffled cards facing down.
2.  Click on any card to flip it over and reveal its icon/image.
3.  Click on a second card to find a match.
4.  If the cards **match**, they stay flipped.
5.  If they **do not match**, they flip back over after a short delay.
6.  The game is won when all pairs are successfully matched!
